## Sorting Algorithm Benchmark

A C++ program that implements and compares several common sorting algorithms using execution time, coomparison counts, and swap/operation counts.

The project was created to explore how different sorting algorithms behave when processing the same dataset and to compare their relative performance.

## Algorithms Implemented
- Selection sort
- Exchange sort
- Bubble sort
- Insertion sort
- Merge sort
- Quick sort
- Heap sort

## Features
- Runs every algorithm against the same dataset
- Measures execution time in microseconds
- Counts comparisons performed by each algorithm
- Tracks swaps
- Uses a test dataset containing 1,000 integers

## What I learned

This project helped reinforce my understanding of how sorting algorithms can accomplish the same goal differently.
It also provided practice in recursion, array manipulation, memory management, operation counting, and measuring program execution time.
